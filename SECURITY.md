# Security Policy

## Reporting

Report security issues privately to the repository owner. Do not open public
issues with exploit details, secrets, or private scan output.

Include:
- affected version or commit
- command used
- expected and actual result
- minimal non-secret reproduction

## Scope

Supported targets are the latest `main` branch and tagged releases once
releases exist.

Raw CodeGuardian reports can contain sensitive paths, findings, or secret
metadata. Keep them out of public issues unless they are redacted.
